This post introduces my side project **Femtochat**, which aims to be a simpler version of [Nanochat][nanochat-github]. It is a personal learning project that I want to share with the world.

I aim to understand how LLMs work under the hood and what the training process looks like. Sharing the code and writing about it creates some external pressure to actually work on it. I hope I can stop procrastinating, publish some results, and, most importantly, learn a lot. As good resources to learn more about LLMs, I can recomment Andrej Karpathy's [videos][karpathy-channel] and his project [Nanochat][nanochat-github], as well as Sebastian Raschka's [books][raschka-manning] and his [Substack][raschka-substack].

[Nanochat][nanochat-github] is an end-to-end implementation of a transformer-based LLM with a decoder architecture, which serves as the foundation for almost all frontier models. I want to create something similar from scratch that is more educational and has lower complexity. Hence, I set out to build a humbler version named **Femtochat**. In the following posts, I will blog the project and show my progress.
